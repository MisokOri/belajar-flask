# belajar-flask

Prototype daftar tugas (Flask + SQLite) untuk latihan CI/CD dan unit test.

```bash
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python run.py          # jalankan web di http://127.0.0.1:5000
python -m pytest -v    # jalankan tes
```
